# Streamlining IT Procurement

**Team ID:** SWTID-2026-6246 
**Platform:** ServiceNow (Flow Designer & Service Catalog)

## Project Overview
This repository contains the phase-wise documentation and implementation evidence for automating standard laptop requests. By leveraging ServiceNow’s Flow Designer, this project eliminates manual triage and routes approved hardware requests directly to the IT fulfillment team.
